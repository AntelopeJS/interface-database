The `SingleSelection<T>` class represents a reference to one document in a table. It extends `Datum<T>` and adds methods that update, replace, delete, and watch that document.

## Class definition

```typescript fragment
class SingleSelection<T> extends Datum<T> {
  update<U>(
    document: (val: ValueProxy<T>) => U,
  ): ExtractType<U> extends DeepPartial<T> ? Query<number> : never;
  update(document: DeepPartial<T> & object): Query<number>;
  replace(document: DeepPartial<T> & object): Query<number>;
  delete(): Query<number>;
  changes(): Query<Changes<T>[]>;
}
```

The `update` overloads resolve as they do on [Selection](./3.selection.md). An argument typed `any` resolves to `never`, with no `.run()`. A type-level read such as `ReturnType<ReturnType<typeof users.get>["update"]>` reads `Query<number>`.

## Create a `SingleSelection`

Calling `get()` on a table produces a `SingleSelection`:

```typescript
import { Schema } from "@antelopejs/interface-database";

const schema = Schema.get("myapp");
if (!schema) throw new Error("Define the myapp schema first");
const users = schema.instance().table("users");

// Get a document by primary key
const user = users.get("user-123");
```

## Read a document

`SingleSelection` extends `Datum`, so you can execute it directly to retrieve the document.

The declared result is `T`, even though a provider can return `null` for a missing key. Check for absence before you access the document. The generic type does not guarantee that the document exists.

```typescript fragment
const user = await users.get("user-123");

if (user) {
  console.log("Found:", user.name);
}

// Access specific fields
const email = await users.get("user-123").key("email");
console.log("Email:", email);

// Transform with do()
const display = await users.get("user-123").do((u) => ({
  label: u.key("name"),
  contact: u.key("email"),
}));
```

## Update a document

The `update` method changes fields in the document. Fields it does not mention stay unchanged. It returns the number of modified documents.

```typescript fragment
// Update with a partial object
const count = await users.get("user-123").update({
  status: "active",
  lastLogin: new Date(),
});

// Update with a function for computed values
await users.get("user-123").update((user) => ({
  loginCount: user.key("loginCount").add(1),
  lastLogin: new Date(),
}));
```

## Replace a document

The `replace` method replaces the whole document with new data.

```typescript fragment
const count = await users.get("user-123").replace({
  _id: "user-123",
  name: "New Name",
  email: "new@example.com",
  role: "user",
});
```

## Delete a document

The `delete` method removes the document from the table and returns the number of deleted documents.

```typescript fragment
const count = await users.get("user-123").delete();

if (count === 1) {
  console.log("User deleted successfully");
}
```

## Monitor changes

The `changes` method returns change events for the document. Each event holds a `changeType`, plus the `oldValue` and `newValue` of the document.

```typescript fragment
for await (const change of users.get("user-123").changes()) {
  console.log("Type:", change.changeType); // "added" | "removed" | "modified"
  console.log("Old:", change.oldValue);
  console.log("New:", change.newValue);
}
```

## Inherited methods

`SingleSelection` extends `Datum`, so it inherits:

- `key()` reads a field by name.
- `default()` gives a fallback value for `null`.
- `do()` applies a transformation function.
- `lookup()` performs a foreign key lookup.
- `pluck()` selects specific fields.
- `cast()` changes the TypeScript type.

See [Datum](./8.datum.md) for the details.
