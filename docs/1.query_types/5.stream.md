The `Stream<T>` class represents a sequence of documents that you can transform, filter, join, group, and aggregate. It extends `Query<T[]>` and is the base of every collection operation in AQL.

## Class definition

```typescript fragment
class Stream<T> extends Query<T[]> {
  // Type casting
  cast<U>(): Stream<U>;

  // Field access
  key<K extends keyof T & string, U = undefined>(
    key: ValueProxyOrValue<K>,
    def?: U & QueryValue,
  ): Stream<U extends undefined ? T[K] : Exclude<T[K], undefined | null> | U>;
  default<U extends QueryValue>(
    val: Value<U>,
  ): Stream<Exclude<T, undefined | null> | U>;

  // Transformation
  map<U>(mapper: (val: ValueProxy<T>) => U): Stream<ExtractType<U>>;
  filter(predicate: (val: ValueProxy<T>) => ValueProxyOrValue<boolean>): this;
  pluck<K extends keyof T & string>(...fields: K[]): Stream<Pick<T, K>>;
  without<K extends keyof T & string>(...fields: K[]): Stream<Omit<T, K>>;

  // Combining
  union<U>(other: Stream<U>): Stream<T | U>;

  // Joining
  join<U, V>(
    right: Stream<U>,
    predicate: (
      left: ValueProxy<T>,
      right: ValueProxy<U>,
    ) => ValueProxyOrValue<boolean>,
    mapper: (left: ValueProxy<T>, right: ValueProxy<U | null>) => V,
  ): Stream<ExtractType<V>>;
  joinInner<U, V>(
    right: Stream<U>,
    predicate: (
      left: ValueProxy<T>,
      right: ValueProxy<U>,
    ) => ValueProxyOrValue<boolean>,
    mapper: (left: ValueProxy<T>, right: ValueProxy<U>) => V,
  ): Stream<ExtractType<V>>;
  lookup<U, TK extends keyof T & string>(
    right: Stream<U>,
    localKey: TK,
    otherKey: FieldPath<U>,
  ): Stream<Omit<T, TK> & Record<TK, T[TK] extends any[] ? U[] : U>>;

  // Grouping
  group<U, K extends (keyof T & string) | string>(
    index: K,
    mapper: (
      stream: Stream<T>,
      group: ValueProxy<K extends keyof T ? T[K] : unknown>,
    ) => U,
  ): Stream<ExtractType<U>>;

  // Ordering and pagination
  orderBy(index: string, direction?: "asc" | "desc"): this;
  slice(offset: Value<number>, count?: Value<number>): this;
  nth(n: Value<number>): Datum<T | null>;

  // Aggregation
  count(field?: keyof T & string): Datum<number>;
  sum(field?: keyof T & string): Datum<number>;
  avg(field?: keyof T & string): Datum<number>;
  min(field?: keyof T & string): Datum<number>;
  max(field?: keyof T & string): Datum<number>;
  distinct(): Datum<T[]>;
  distinct(field: undefined): Datum<T[]>;
  distinct<TK extends keyof T & string>(field: TK): Stream<T[TK]>;

  // Change feeds
  changes(): Query<Changes<T>[]>;
}
```

## Field access

`key()` reads one field from every document in the stream. `default()` gives a fallback value for `null` values.

`key(field, fallback)` takes a field name, or a `ValueProxy` that yields one, and an optional fallback. When the fallback is not `undefined`, the result type drops `null` and `undefined` from the field type and adds the fallback's type. Without a fallback, the declared field type is unchanged.

```typescript fragment
const users = schema.instance().table("users");

// Extract a single field
const emails = await users.key("email");

// Provide a default value
const phones = await users.key("phone").default("N/A");
```

## Transform data

### `map()`

Transforms each document with a mapping function. The callback receives a `ValueProxy<T>` to build expressions with.

```typescript fragment
const profiles = await users.map((user) => ({
  id: user.key("_id"),
  displayName: user.key("name"),
  contact: user.key("email"),
}));
```

### `filter()`

Keeps the documents that match a predicate. The callback returns a boolean expression.

```typescript fragment
const active = await users.filter((user) =>
  user.key("status").eq("active").and(user.key("age").ge(18)),
);
```

### `pluck()` and `without()`

`pluck()` keeps only the named fields of every document, and `without()` removes them. Both accept only field names of `T`.

```typescript fragment
// Keep only specific fields
const slim = await users.pluck("_id", "name", "email");

// Remove sensitive fields
const safe = await users.without("password", "ssn");
```

## Combine streams

### `union()`

Concatenates two streams without deduplication.

```typescript fragment
const allPremium = await users
  .filter((u) => u.key("plan").eq("premium"))
  .union(users.filter((u) => u.key("plan").eq("enterprise")));
```

## Join data

### `join()` for a left join

Performs a left join between two streams. Every document from the left stream appears in the result. When no right document matches, the right side is `null`.

```typescript fragment
const usersWithOrders = await users.join(
  schema.instance().table("orders"),
  (user, order) => order.key("userId").eq(user.key("_id")),
  (user, order) => ({
    userName: user.key("name"),
    orderTotal: order.key("amount").default(0),
  }),
);
```

### `joinInner()` for an inner join

Performs an inner join. Only documents with a match on both sides appear in the result.

```typescript fragment
const matched = await users.joinInner(
  schema.instance().table("orders"),
  (user, order) => order.key("userId").eq(user.key("_id")),
  (user, order) => ({
    userName: user.key("name"),
    amount: order.key("amount"),
  }),
);
```

### `lookup()`

Replaces a foreign key field, or a list of foreign keys, with the referenced documents from another stream. See [Lookup](../2.operations/7.lookup.md) for the details.

```typescript fragment
const postsWithAuthors = await schema
  .instance()
  .table("posts")
  .lookup(schema.instance().table("users"), "authorId", "_id");
```

## Group data

The `group` method splits the stream by an index value, then applies a mapping function to each group. The mapper receives the stream of the group's documents and the group key. Each mapper result is one element of the new stream.

```typescript fragment
const statsByRole = await users.group("role", (stream, role) => ({
  role: role,
  total: stream.count(),
  avgAge: stream.avg("age"),
}));
```

## Order and paginate

### `orderBy()`

Sorts the stream by an index field, in ascending or descending order. The name is an index of the table, or else a field. A dotted name is a nested path, so `orderBy("title.fr")` sorts on `fr` inside `title`.

```typescript fragment
const sorted = await users.orderBy("name", "asc");
const newest = await users.orderBy("createdAt", "desc");
```

### `slice()`

Takes a subsection of the stream, from an offset and for a number of documents, for pagination.

```typescript fragment
const page1 = await users.orderBy("createdAt").slice(0, 10);
const page2 = await users.orderBy("createdAt").slice(10, 10);
```

### `nth()`

Retrieves one document by its position in the stream. Returns a `Datum<T | null>`.

```typescript fragment
const first = await users.orderBy("createdAt").nth(0);
```

## Aggregate data

These aggregation methods return a `Datum<number>`. `count(field)` counts the distinct values of the field, and `count()` counts the documents.

```typescript fragment
const totalUsers = await users.count();
const distinctEmails = await users.count("email");
const totalSales = await schema.instance().table("orders").sum("amount");
const avgOrder = await schema.instance().table("orders").avg("amount");
const maxOrder = await schema.instance().table("orders").max("amount");
const minOrder = await schema.instance().table("orders").min("amount");
```

### `distinct()`

Without a field, `distinct()` returns a `Datum` of the deduplicated documents. With a field, it returns a `Stream` of that field's distinct values.

```typescript fragment
// All distinct documents
const unique = await users.distinct();

// Distinct values of a field
const roles = await users.distinct("role");
```

## Change feeds

The `changes` method turns the stream into a feed of real-time change notifications.

```typescript fragment
for await (const change of users.changes()) {
  console.log(change.changeType, change.oldValue, change.newValue);
}
```

An open-ended feed may never produce a completed array. Consume the events one at a time, and stop the loop when the consumer no longer needs them.

See [Change feeds](./6.feed.md) for the details.
