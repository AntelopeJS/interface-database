title: Datum
description: The Datum query type for a single value, with its field access, default, transformation, lookup, pluck, and cast methods.

---

The `Datum<T>` class represents a single value in a query. It extends `Query<T>` and adds methods that read fields, apply transformations, and perform foreign key lookups on that value.

## Class definition

```typescript fragment
class Datum<T> extends Query<T> {
  cast<U>(): Datum<U>;
  key<K extends keyof NonNullable<T> & string, U = undefined>(
    key: K,
    def?: U & QueryValue,
  ): Datum<
    U extends undefined ? NonNullable<T>[K] : NonNullable<NonNullable<T>[K]> | U
  >;
  default<U extends QueryValue>(
    val: Value<U>,
  ): Datum<Exclude<T, undefined | null> | U>;
  do<U>(mapper: (val: ValueProxy<T>) => U): Datum<ExtractType<U>>;
  lookup<U = any, TK extends keyof T & string = keyof T & string>(
    other: Stream<U>,
    localKey: TK,
    otherKey: keyof U & string,
  ): Datum<Omit<T, TK> & Record<TK, T[TK] extends any[] ? U[] : U>>;
  pluck<K extends keyof NonNullable<T> & string>(
    ...fields: K[]
  ): Datum<Pick<NonNullable<T>, K> | Extract<T, null | undefined>>;
}
```

## Field access

The `key` method reads a field from a document datum. Chain `key` calls to read a nested field. A fallback that is not `undefined` removes `null` and `undefined` from the declared field type and adds the fallback's type. Without a fallback, the declared field type is unchanged.

```typescript
import { Schema } from "@antelopejs/interface-database";

const schema = Schema.get("myapp");
if (!schema) throw new Error("Define the myapp schema first");
const users = schema.instance().table("users");

// Access a field
const name = await users.get("user-123").key("name");

// Access a nested field
const city = await users.get("user-123").key("address").key("city");

// Provide a default value
const phone = await users.get("user-123").key("phone", "N/A");
```

## Default values

The `default` method gives a fallback value for a datum that is `null`.

```typescript fragment
const user = await users.get("maybe-missing").default({
  _id: "guest",
  name: "Guest User",
  role: "visitor",
});
```

## Transform with `do()`

The `do` method applies a transformation function to the datum. The callback receives a `ValueProxy<T>`, whose operators build expressions.

```typescript fragment
const formatted = await users.get("user-123").do((user) => ({
  displayName: user.key("name"),
  contact: user.key("email"),
  hasPhone: user.key("phone").ne(undefined),
}));
```

## Foreign key lookup

The `lookup` method replaces a foreign key field with the referenced document from another stream, such as a table. A field that holds a list of keys becomes a list of documents.

```typescript
import { Schema } from "@antelopejs/interface-database";

interface Post {
  _id: string;
  title: string;
  authorId: string;
}

interface User {
  _id: string;
  name: string;
}

const blog = Schema.get<{ posts: Post; users: User }>("blog");
if (!blog) throw new Error("Define the blog schema first");
const post = await blog
  .instance()
  .table("posts")
  .get("post-1")
  .lookup(blog.instance().table("users"), "authorId", "_id");

// post.authorId is now the full User object
console.log(post.authorId.name);
```

## Field selection

The `pluck` method keeps the named fields of a document datum and discards the rest.

```typescript fragment
const profile = await users.get("user-123").pluck("name", "email", "avatar");
```

## Type casting

The `cast` method changes the TypeScript type of the datum and performs no runtime conversion. Use it when the actual type differs from what the compiler infers. Nothing checks that the new type matches what the query returns.

```typescript fragment
const raw = users.get("user-123").cast<{ name: string; role: string }>();
```
