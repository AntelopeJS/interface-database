A table holds documents in AQL. You get one from a `SchemaInstance`, and it has methods to insert, retrieve, and query documents.

## Access a table

Get a table reference from a schema instance:

```typescript
import { Schema } from "@antelopejs/interface-database";

const schema = Schema.get("myapp");
if (!schema) throw new Error('Schema "myapp" is not defined');

const db = schema.instance();
const users = db.table("users");
```

## Type-safe tables

Give the table-to-document mapping to `Schema`, not to `table()`:

```ts docs-check
import { Schema } from "@antelopejs/interface-database";

interface User {
  _id: string;
  name: string;
  email: string;
  status: string;
  role: string;
  createdAt: Date;
  age: number;
}

const schema = new Schema<{ users: User }>("myapp", {
  users: {
    fields: {
      name: "string",
      email: "string",
      status: "string",
      role: "string",
      createdAt: "date",
      age: "number",
    },
    indexes: { role: {}, createdAt: {}, name: {} },
  },
});
const users = schema.instance().table("users");

// TypeScript now checks field names and types
export async function readUser() {
  const user = await users.get("user-123"); // Declared as User
  const emails = await users.key("email"); // string[]
  return { user, emails };
}
```

`get()` returns `SingleSelection<User>`, so awaiting it is typed as `User`, not `User | null`. The type does not guarantee that a row exists: a provider may return `null` or `undefined` for a missing key. Check the result before you read its fields. The mapping on `Schema` describes documents. It does not validate what the database holds.

## Basic operations

### Retrieve all documents

A table reference is also a stream of all its documents:

```typescript fragment
const allUsers = await users;
console.log(`Total users: ${allUsers.length}`);
```

### Retrieve by primary key

```typescript fragment
const user = await users.get("user-123");

if (user) {
  console.log("Found:", user.name);
}
```

### Retrieve by secondary index

```typescript fragment
const admins = await users.getAll("admin", "role");
```

Without an index name, `getAll()` matches the primary key.

### Retrieve by range

`between()` takes an index name, a lowest value, and a highest value. The highest value is excluded.

```typescript fragment
const recent = await users.between(
  "createdAt",
  new Date("2024-01-01"),
  new Date(),
);
```

## Chain operations

`Table` extends `Selection`, which extends `Stream`, so you can chain any stream operation on a table:

```typescript fragment
// Filter and sort
const activeByName = await users
  .filter((u) => u.key("status").eq("active"))
  .orderBy("name");

// Paginate
const page = await users.orderBy("createdAt").slice(0, 10);

// Aggregate
const count = await users.count();
const avgAge = await users.avg("age");

// Transform
const names = await users.map((u) => u.key("name"));
```

## Insert documents

```typescript fragment
// Single document
const ids = await users.insert({
  name: "Alice",
  email: "alice@example.com",
  status: "active",
});

// Multiple documents
const batchIds = await users.insert([
  { name: "Bob", email: "bob@example.com", status: "active" },
  { name: "Carol", email: "carol@example.com", status: "active" },
]);

// Upsert (update on conflict)
await users.insert(
  { _id: "user-123", name: "Updated" },
  { conflict: "update" },
);
```
