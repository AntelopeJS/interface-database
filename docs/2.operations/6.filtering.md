This guide shows how to select, compare, and transform documents with `filter()` and the `ValueProxy` operators. The examples use this table:

```typescript
import { Schema } from "@antelopejs/interface-database";

const schema = Schema.get("myapp");
if (!schema) throw new Error('Schema "myapp" is not defined');

const users = schema.instance().table("users");
```

## Basic filtering

Call `filter()` with a predicate function. The predicate receives a `ValueProxy<T>` that stands for each document.

```typescript fragment
const active = await users
  .filter((user) => user.key("status").eq("active"))
  .run();
```

## Comparison operators

### Equality and inequality

```typescript fragment
const admins = await users.filter((u) => u.key("role").eq("admin")).run();
const nonAdmins = await users.filter((u) => u.key("role").ne("admin")).run();
```

### Numeric comparisons

```typescript fragment
const adults = await users.filter((u) => u.key("age").ge(18)).run();
const seniors = await users.filter((u) => u.key("age").gt(65)).run();
const young = await users.filter((u) => u.key("age").lt(18)).run();
const discounted = await users.filter((u) => u.key("age").le(25)).run();
```

## Logical operators

Combine conditions with `and()`, `or()`, and `not()`:

```typescript fragment
// AND
const verified = await users
  .filter((u) =>
    u.key("status").eq("active").and(u.key("emailVerified").eq(true)),
  )
  .run();

// OR
const important = await users
  .filter((u) => u.key("role").eq("admin").or(u.key("plan").eq("premium")))
  .run();

// NOT
const standard = await users
  .filter((u) => u.key("plan").eq("premium").not())
  .run();

// Complex combinations
const target = await users
  .filter((u) =>
    u
      .key("status")
      .eq("active")
      .and(u.key("plan").eq("premium").or(u.key("totalPurchases").gt(500))),
  )
  .run();
```

## String operations

`match()` takes a regular expression as a string.

```typescript fragment
// Case-insensitive match
const bobs = await users
  .filter((u) => u.key("name").downcase().eq("bob"))
  .run();

// Regex matching
const gmailUsers = await users
  .filter((u) => u.key("email").match("@gmail\\.com$"))
  .run();

// String concatenation in filter
const fullNameMatch = await users
  .filter((u) => u.key("firstName").concat(u.key("lastName")).eq("JohnSmith"))
  .run();
```

## Date filtering

### Date comparisons

```typescript fragment
const newUsers = await users
  .filter((u) => u.key("createdAt").gt(new Date("2024-01-01")))
  .run();

const q1Users = await users
  .filter((u) =>
    u
      .key("createdAt")
      .ge(new Date("2024-01-01"))
      .and(u.key("createdAt").lt(new Date("2024-04-01"))),
  )
  .run();
```

### Date components

```typescript fragment
const thisYear = await users
  .filter((u) => u.key("createdAt").year().eq(2024))
  .run();

const morningLogins = await users
  .filter((u) => u.key("lastLogin").hours().lt(12))
  .run();
```

## Array operations

```typescript fragment
// Check array contents
const jsPosts = await schema
  .instance()
  .table("posts")
  .filter((post) => post.key("tags").includes("javascript"))
  .run();

// Check array length
const wellTagged = await schema
  .instance()
  .table("posts")
  .filter((post) => post.key("tags").count().gt(3))
  .run();

// Check if empty
const untagged = await schema
  .instance()
  .table("posts")
  .filter((post) => post.key("tags").isempty())
  .run();
```

## Default values in filters

To compare a field that may be null, give it a fallback with `default()`:

```typescript fragment
const activeUsers = await users
  .filter((u) => u.key("active").default(false).eq(true))
  .run();

const frequentVisitors = await users
  .filter((u) => u.key("visits").default(0).gt(10))
  .run();
```

## Ordering and pagination

`orderBy()` takes the name of the index to sort by and an optional direction, `"asc"` or `"desc"`. `slice()` takes an offset and a count.

```typescript fragment
// Sort ascending
const byName = await users.orderBy("name", "asc").run();

// Sort descending
const newest = await users.orderBy("createdAt", "desc").run();

// Paginate
const page1 = await users.orderBy("createdAt").slice(0, 10).run();
const page2 = await users.orderBy("createdAt").slice(10, 10).run();
```

## Performance tips

1. Use `getAll()` and `between()` with an index instead of `filter()` where you can. An index lookup avoids the full table scan that a `filter()` runs.
2. Filter early in the query chain, so later transformations and aggregations see fewer documents.
3. Limit result sets with `slice()` to avoid transferring data you do not use.
4. Keep filter predicates simple when a simpler predicate gives the same result.

```typescript fragment
// Slower: full table scan with filter
const slow = await users
  .filter((u) => u.key("email").eq("user@example.com"))
  .run();

// Faster: index-based lookup
const fast = await users.getAll("user@example.com", "email").run();
```
