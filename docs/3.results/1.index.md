## Common patterns

Every AQL operation follows the same pattern:

1. Build a query by chaining operations.
2. Run the query with `run()` to get the result.
3. Process the result.

```typescript
import { Schema } from "@antelopejs/interface-database";

interface User {
  _id: string;
  name: string;
  email: string;
  status: string;
}

const schema = new Schema<{ users: User }>("myapp", {
  users: {
    fields: { name: "string", email: "string", status: "string" },
    indexes: {},
  },
});

const users = schema.instance().table("users");

// Insert returns the IDs of the inserted documents
const ids = await users
  .insert({ name: "Alice", email: "alice@example.com" })
  .run();
console.log("New ID:", ids[0]);

// Update returns the number of modified documents
const count = await users.get("user-123").update({ status: "active" }).run();
console.log(`Modified ${count} documents`);

// Delete returns the number of deleted documents
const deleted = await users.get("user-123").delete().run();
console.log(`Deleted ${deleted} documents`);
```
