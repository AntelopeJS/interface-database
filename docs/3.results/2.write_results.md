title: Write results
description: What insert, update, replace, and delete resolve to in AQL, from the inserted IDs to the count of modified documents.
mode: reference
---

`Table<T>.insert()` returns a `Query<string[]>` that resolves to the primary keys of the inserted documents, generated or provided.

## Return value

```typescript fragment
// Insert returns string[] (the IDs of inserted documents)
const ids: string[] = await users.insert({
  name: "Alice",
  email: "alice@example.com",
});
```

## Examples

### Single document insert

```typescript
import { Schema } from "@antelopejs/interface-database";

interface User {
  _id: string;
  name: string;
  email: string;
}

const schema = Schema.get<{ users: User }>("myapp");
if (!schema) throw new Error('Schema "myapp" is not defined');

const users = schema.instance().table("users");

const ids = await users.insert({
  name: "John Doe",
  email: "john@example.com",
});

console.log("Inserted document ID:", ids[0]);
```

### Multiple document insert

```typescript fragment
const ids = await users.insert([
  { name: "Alice", email: "alice@example.com" },
  { name: "Bob", email: "bob@example.com" },
  { name: "Carol", email: "carol@example.com" },
]);

console.log(`Inserted ${ids.length} documents`);
console.log("IDs:", ids);
```

### Insert with conflict handling

The `conflict` option, `"update"` or `"replace"`, sets what happens when a document with the same primary key already exists:

```typescript fragment
// Update matching fields on conflict
const ids = await users.insert(
  { _id: "user-123", name: "Updated Name", lastSeen: new Date() },
  { conflict: "update" },
);

// Replace the entire document on conflict
const ids2 = await users.insert(
  { _id: "user-123", name: "Replaced", email: "new@example.com" },
  { conflict: "replace" },
);
```

## Update and delete results

`update()`, `replace()`, and `delete()` on a `Selection<T>` or a `SingleSelection<T>` return a `Query<number>`. For `update()` and `replace()`, the number is the count of modified documents. For `delete()`, it is the count of deleted documents.

```typescript fragment
// Update returns the number of modified documents
const updated = await users.get("user-123").update({ status: "active" });
console.log(`Modified: ${updated}`);

// Replace returns the number of modified documents
const replaced = await users.get("user-123").replace({
  _id: "user-123",
  name: "New",
  email: "new@example.com",
});
console.log(`Replaced: ${replaced}`);

// Delete returns the number of deleted documents
const deleted = await users
  .filter((u) => u.key("status").eq("inactive"))
  .delete();
console.log(`Deleted: ${deleted}`);
```

`update()` has two overloads. A function argument returns `Query<number>` when the object it builds fits the document type, and `never` otherwise. A partial document returns `Query<number>`. A value typed `any` matches the function overload, so that call is typed `never`.

Read through its type, `update()` resolves to the plain document overload. `ReturnType<typeof users.update>` is `Query<number>`, so the result of `run()` is a `number`:

```typescript
import { Schema } from "@antelopejs/interface-database";

interface User {
  _id: string;
  name: string;
  status: string;
}

const schema = new Schema<{ users: User }>("myapp", {
  users: { fields: { name: "string", status: "string" }, indexes: {} },
});
const users = schema.instance().table("users");

type Modified = Awaited<ReturnType<ReturnType<typeof users.update>["run"]>>;

const modified: Modified = await users
  .get("user-123")
  .update({ status: "active" });
console.log(`Modified: ${modified}`);
```
