In AQL, the schema definition declares indexes. You do not create them at runtime. The declaration names the fields to index and the kind of index.

## `IndexDefinition`

```typescript
interface IndexDefinition {
  fields?: string[]; // Fields for compound indexes
  multi?: boolean; // Multi-valued index
  crossInstance?: boolean; // Also serve CROSS_INSTANCE queries efficiently
  unique?: boolean; // Refuse a second row with the same key in an instance
}
```

## Define indexes

Each table definition declares its indexes in its `indexes` property:

```typescript
import { Schema } from "@antelopejs/interface-database";

const schema = new Schema("myapp", {
  users: {
    fields: { name: "string", email: "string", role: "string" },
    indexes: {
      email: {}, // Simple index (field name = index name)
      role: {}, // Simple index
      name_role: { fields: ["name", "role"] }, // Compound index
    },
  },
});
```

### Simple indexes

Without `fields`, the index name is the field name:

```typescript fragment
indexes: {
  email: {},  // Creates an index on the "email" field
}
```

### Compound indexes

`fields` lists the fields of an index that spans several fields:

```typescript fragment
indexes: {
  full_name: { fields: ["firstName", "lastName"] },
}
```

### Multi indexes

`multi: true` indexes each element of an array field on its own:

```typescript fragment
indexes: {
  tags: { multi: true },
}
```

### Cross-instance indexes

`crossInstance: true` marks an index that queries run with `CROSS_INSTANCE` use. The driver then also maintains an index usable across all instances. Without it, the index is optimized for queries scoped to one instance, and cross-instance queries that use it may be slow. The flag never changes results:

```typescript fragment
indexes: {
  status: { crossInstance: true },
}
```

## Use indexes in queries

`getAll()` and `between()` query through a defined index:

```typescript fragment
const db = schema.instance();
const users = db.table("users");

// Lookup by secondary index
const admins = await users.getAll("admin", "role");

// Range query on an indexed field
const recent = await users.between(
  "createdAt",
  new Date("2024-01-01"),
  new Date(),
);
```
